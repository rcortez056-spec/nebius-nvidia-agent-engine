# Nebius NVIDIA Agent Engine

Autonomous multi-agent workflow engine powered by NVIDIA Nemotron and Nebius Token Factory.

## Overview
This repository contains the architecture and implementation for high-frequency autonomous agent workflows, optimized for speed and token efficiency using Nebius infrastructure and NVIDIA open-source models.

## Requirements
* Python 3.10+
* Nebius Token Factory API Key
* NVIDIA API access

## Quick Start
1. Clone the repository:
   
 git clone https://github.com/rcortez056-spec/nebius-nvidia-agent-engine.git  
   cd nebius-nvidia-agent-engine
# Install dependencies
pip install -r requirements.txt

# Set your API key environment variable
export NEBIUS_API_KEY="your-api-key-here"

# Execute the engine
python main.py
